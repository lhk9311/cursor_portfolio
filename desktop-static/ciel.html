Key Technical Points

01

K6 부하테스트 — XSSF vs SXSSF 성능 비교

대용량 엑셀 다운로드 API(10,112건)에 대해 K6로 동시 사용자 10명 → 50명 시나리오로 부하테스트를 진행하였습니다. XSSF(기존)는 평균 응답시간 89ms로 빠르지만 전체 데이터를 힙에 올리는 구조상 동시 50명 + 힙 64MB 제한 조건에서 OOM이 발생하여 서버가 다운됐습니다. SXSSF(개선)는 평균 응답시간 16.63s로 느리지만 페이징 스트리밍 방식으로 고부하 상황에서도 전 요청이 정상 완료됐습니다. 속도보다 서버 안정성을 우선한 리팩토링 근거를 수치로 검증했습니다. K6 결과를 InfluxDB에 저장하고 Grafana로 시각화하는 모니터링 환경도 구축했습니다.
